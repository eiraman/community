# Eiraman community

How the Eiraman project is run, and how to take part. Status: **draft**, not yet in force.

| File | What it says |

| [MAINTAINERS.md](MAINTAINERS.md) | Holders of each role (placeholders); the source for `CODEOWNERS` |
| [PATHWAYS.md](PATHWAYS.md) | Where to start, for each kind of contributor |
| [CASE-STUDY-TEMPLATE.md](CASE-STUDY-TEMPLATE.md) | Template for adopters' case studies, filed in [`cases/`](cases/) |

| [CHANGELOG.md](CHANGELOG.md) | Changes to these documents per release |
| [`meetings/`](meetings/) | Public notes of working group and Steering Committee meetings |
